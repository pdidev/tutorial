# Dask-Enabled In Situ Analytics

This directory contains an example showing how Deisa[1] can be used.

You may locally run this exercise using the `launch-local.sh` script.
This will start a local Dask scheduler with 1 worker, run the simulation and the analytics code.

## How it works ?

This example uses the PDI **pycall** plugin to retrieves simulation data, start a Deisa Bridge instance, and sends the data to the Dask workers.

Internally, a *Deisa Bridge* is created per MPI process.
Once a piece of data is shared with PDI, the Bridge sends it to a worker that has been chosen in a round-robin fashion.

The Deisa Python library is used from the analytics side to retrieve a Dask arrays describing the data generated by the simulation.
Deisa perfoms a "handshake", which waits for all MPI ranks (or bridges) to be ready.


## Files :

- `main.c`: simulation code;
- `config.yml`: PDI specification tree;
- `client.py`: python script for analytics;
- `launch-local.sh`: the script that runs both the simulation and Dask cluster
